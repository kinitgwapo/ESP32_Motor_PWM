### Circuit Specifications

DC Motor: 3V Required

L298N Supplied Power: 5V 3A Samsung Charger

L298N OUT1-2 Vout: 3.3V (5V - 1.7V[L298N Circuit VDrop])

| PWM   | DC Motor State |
| :---: | :------------: |
| 0     | Stationary     |
| 48-49 | Starting       |
